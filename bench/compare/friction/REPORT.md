**In short, against design §3.** Read by hand from the run below:
- **kontext v0.3.0:** the same counts as design §3.1b: 5 + 1 commands, 3–6 manual steps (3 here), 1 account, 2 secrets. The v0.2.0 path in the 2026-11-15 report was 5 + 3 (+1 conditional), 5–7 (5 here), 1 and 2. The first `kontext setup` created the project and installed the hooks, then exited 4 asking for a Cloudflare token. No counted command set `KONTEXT_ACTOR`, and B found what A saved after joining with the line from `kontext invite`.
- **kontext, how the server was stood in for:** `server deploy` was not run. The second `kontext setup` ran against the local sidecar with its admin secret, standing in for the `setup` after a real deploy. `join` refuses a server on plain http unless it is the same machine (`src/invite.rs`), and the sidecar has no TLS, so A and B each forward `localhost:8787` to it. Those are the two uncounted "forward" rows. The harness row that stands in for the agent saving something sets `KONTEXT_ACTOR=agent:bench`; without it, the entry is saved as `agent:unknown`.
- **The other setups:** the same counts and step statuses as the 2026-11-15 report. gentle-ai's installer from `main` installed 4.5.0, and Beads' installed 1.3.4, the versions the arms' images pin.
- **OpenSpec and plain:** the same counts as the design.
- **The PATH steps** of kontext, Beads and gentle-ai were not needed on Debian: a new login shell already puts `~/.local/bin` on PATH, through `~/.profile`. kontext's installer, with `~/.local/bin` off PATH, printed its next command with the full path and changed no shell file.
- **Beads:** this table counts the pinned Dolt install as a manual step on each machine, where the design counted it as a command. Its installer again ended with "Error: bd was installed but is not in PATH" (the step checks that `bd` was installed).
- **mem0:** 5–6 manual steps against the design's 4–5: sign up, create a key, carry it to B, restart Claude Code on A and on B, plus a shared `user_id` if personal memories should travel. The install commands ran; nothing that needs the account did.
- **gentle-ai (git sync):** 0–1 manual steps against 1–2. The flags replace the TUI choices, and the new terminal after the rc edit was not needed on Debian.
- **claude-mem:** `unzip` is installed before `npx claude-mem install` on each machine, as in the 2026-11-15 run that found Bun's installer needs it (design note 16). This run did not try without it.
- **Base image:** `bench-base:latest` is not the image of the 2026-11-15 report. It was rebuilt after it (design note 17 adds `python-is-python3`).
- **Not executed:** every step that needs an account (Cloudflare, Mem0, cmem.ai, a host for Engram Cloud) is counted only. That includes kontext's `server deploy` and the workers.dev subdomain prompt.
