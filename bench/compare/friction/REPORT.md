**In short, against design §3.** Read by hand from the run below:
- **kontext and gentle-ai (git sync):** the same command counts.
- **OpenSpec and plain:** the same counts.
- **The PATH steps** of kontext, Beads and gentle-ai were not needed on Debian: a new login shell already puts `~/.local/bin` on PATH, through `~/.profile`. On macOS's zsh they would be.
- **Beads:** the same steps, but this table counts the pinned Dolt install as a manual step on each machine, where the design counted it as a command. Its installer also exits 1 ("bd was installed but is not in PATH") until `~/.local/bin` is on PATH.
- **mem0:** the same steps as the design's list, but they add up to 5–6, not the 4–5 it states: sign up, create a key, carry it to B, restart Claude Code on A and on B, plus a shared `user_id` if personal memories should travel. The install commands ran; nothing that needs the account did.
- **gentle-ai (git sync):** one manual step fewer (0–1 against 1–2). The flags replace the TUI choices, and the new terminal after the rc edit was not needed on Debian. The friction run follows the docs' install command from `main`; the arm's image pins v4.5.0.
- **claude-mem:** its installer needs `unzip` (for Bun), which a slim Debian lacks. That adds a manual step on each machine that its docs do not mention.
- **Not executed:** every step that needs an account (Cloudflare, Mem0, cmem.ai, a host for Engram Cloud) is counted only. kontext's real `server deploy` was not run; B joined A through the local sidecar instead.
